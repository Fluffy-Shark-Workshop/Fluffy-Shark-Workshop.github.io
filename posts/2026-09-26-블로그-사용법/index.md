공부한 내용을 빠르게 올리려고 만든 블로그입니다. Markdown, HTML, PDF, 이미지를 올리면 **내용 전체**가 본문에 그대로 펼쳐집니다.

## 가장 빠른 방법: 글쓰기 도구

1. 블로그 폴더의 `블로그 글쓰기.bat`을 실행합니다. 올릴 파일들을 이 아이콘 위에 끌어다 놓으면 그 파일들이 담긴 채로 열립니다.

2. 브라우저에 열린 글쓰기 화면에 파일을 더 끌어다 놓거나 **파일 선택**으로 고릅니다.

3. 제목, 카테고리, 태그를 적습니다. 카테고리와 태그는 입력하는 동안 이미 쓰던 이름이 자동완성됩니다.

4. **게시하기**를 누르면 1~2분 뒤 블로그에 반영됩니다.

글쓰기 도구의 **글 관리** 탭에서는 이미 올린 글의 제목, 카테고리, 태그, 본문을 고치고, 태그나 카테고리 이름을 모든 글에서 한꺼번에 바꿀 수 있습니다.

## 글 하나의 구조

글 하나는 `posts/` 아래의 폴더 하나입니다. 폴더 안의 `index.md`가 글 정보와 본문이고, 나머지 파일이 첨부 파일입니다.

```text
posts/
└─ 2026-09-26-에피폴라-기하학/
   ├─ index.md
   ├─ 19_에피폴라_기하학_v1.1.md
   ├─ 필기1.png
   └─ 필기2.png
```

`index.md` 맨 위에는 글 정보를 적습니다. 카테고리는 `/`로 하위 카테고리를 만들 수 있습니다.

```yaml
---
title: 에피폴라 기하학 정리
date: 2026-09-26 14:30
category: 공부/Visual SLAM
tags: [SLAM, 에피폴라, 기본행렬]
---
```

## 첨부 파일 넣기

본문에 이미지 문법으로 파일 이름을 적으면 종류에 맞게 전체가 보입니다.

| 적는 법 | 보이는 모습 |
| --- | --- |
| `![](필기1.png)` | 이미지. 본문 폭에 맞춰 크게 보이고, 누르면 확대됩니다. |
| `![](강의자료.pdf)` | 문서 PDF는 모든 쪽을 틀 안에 차례대로 펼칩니다. |
| `![](필기.pdf)` | 삼성 노트로 내보낸 PDF는 필기 이미지처럼 쪽 사이 틈 없이 이어 붙여, 쪽 경계에서 필기가 잘리지 않습니다. |
| `![](보고서.html)` | HTML 페이지를 높이 전체 그대로 보여 줍니다. |
| `![](정리.md)` | 다른 Markdown 파일의 내용을 이 자리에 넣습니다. |
| `![](코드.zip)` | 내려받기 카드를 만듭니다. |

이미지를 연달아 적을 때는 줄바꿈으로 간격을 정합니다.

```markdown
![](필기1.png)
![](필기2.png)     ← 바로 아랫줄에 적으면 두 이미지가 틈 없이 붙습니다

![](필기3.png)     ← 빈 줄을 두면 간격을 두고 떨어집니다
```

## 수식

`$...$`는 문장 속 수식이고 `$$`로 감싼 줄은 크게 가운데 정렬된 수식입니다. 보고서 작성 가이드의 규칙을 그대로 쓰면 됩니다. 꼭지 아래 네 칸 들여쓰기, `aligned` 안의 `\\` 줄바꿈, 표 안의 수식이 모두 깨지지 않습니다. 예를 들어 $R^\top R = I$ 이고 아래처럼 보입니다.

$$
\begin{aligned}
L ={}& L_1 \\
     &+ \lambda_2 L_2 \\
     &+ \lambda_3 L_3
\end{aligned}
$$

여러 종류의 첨부 파일이 실제로 어떻게 보이는지는 [첨부 파일 표시 예시](../2026-09-26-첨부-파일-표시-예시/) 글에서 볼 수 있습니다.
